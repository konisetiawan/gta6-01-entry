Solmar is an original open-world crime game set in a sun-soaked fictional coastal city. Drive and steal cars, weave through traffic and pedestrians, and manage a wanted level as police close in. Five story missions lead from small favors to a major score. Built with plain JavaScript and Canvas 2D, it has no build step and makes no network requests.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080. Controls: WASD or arrows move and drive, E enter or exit a car, Space punch, Shift sprint, P pause, M mute, R restart.
